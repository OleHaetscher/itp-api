Interpersonal Transaction Protocol

API mock client

A stand-in for the JavaScript application, so the interaction workflow can be walked through by hand. It talks to the API the way a browser client will: bearer token, six-digit invitations, long-polled perceptions, behavior vectors validated against the state space schema the model declares. Every request and response is on the right.

Creating registers you and starts polling. With two models the server plays both and the interaction is over before the response returns.
